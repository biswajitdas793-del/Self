## HR & TALENT MANAGEMENT (20 Prompts)

### Resume & Candidate Screening

**1. Resume Screening for Specific Role**
```
Role: Resume Screener
Task: Evaluate candidate fit

You are an expert recruiter. I'm hiring for a [POSITION] role. 
Key qualifications needed:
- [Requirement 1]
- [Requirement 2]
- [Requirement 3]
- [Requirement 4]
- [Requirement 5]

Please screen the attached resume. Rate overall fit 1-10 and provide:
1. Strengths (2-3 key strengths matching our needs)
2. Gaps (any missing qualifications)
3. Red flags (anything concerning)
4. Overall recommendation (Move forward/Hold/Pass)

Format your response as a structured evaluation.
```

**2. Compare Multiple Resumes**
```
I'm screening candidates for [POSITION]. I've attached 5 resumes.
Please analyze all 5 and:
1. Rank them 1-5 by qualification fit
2. For each: 1-2 sentence summary of key strengths
3. Identify any standouts or concerns
4. Recommend top 3 for interviews with justification
```

**3. Extract Key Information from Resume**
```
Extract the following information from this resume in a structured table:
- Name and contact info
- Years of relevant experience
- Education (degrees, universities, graduation year)
- Technical skills (list all mentioned)
- Leadership experience (any people management)
- Industry background
- Notable achievements or awards

Format as a clean table for ATS input.
```

## CUSTOMER SUPPORT & SERVICE (15 Prompts)

### Response Templates

**1. First Response to Support Ticket**
```
Create a template for initial support ticket response for [ISSUE_TYPE].

Issue type: [CATEGORY]
Typical customer emotion: [FRUSTRATED/CONFUSED/URGENT]
Expected resolution path: [SIMPLE/MODERATE/COMPLEX]
Typical urgency: [SLA]

Template should:
1. Acknowledge their issue (show you understand the problem)
2. Express empathy (validate their frustration)
3. Assure them of solution (we'll get this resolved)
4. Next immediate step (what you'll do)
5. Timeline expectation (when they'll hear back)
6. Escalation path (if needed)
7. Proactive resource (link to knowledge base if relevant)

Keep tone warm but professional. Include variables for personalization [LIKE_THIS].
```

**2. Complex Issue Troubleshooting Response**
```
Create a detailed troubleshooting response template for [ISSUE].

Issue: [SPECIFIC_PROBLEM]
Typical root causes: [LIST_COMMON_CAUSES]
Complexity level: Requires troubleshooting steps
Target: Get customer to solution without escalation if possible

Response should:
1. Validate their issue (acknowledge you understand)
2. Explain what we'll investigate
3. Provide step-by-step troubleshooting
   - Each step with clear instructions
   - What to look for
   - Possible results
4. Decision tree (what to do based on results)
5. If they can't resolve:
   - When to escalate
   - What to prepare for escalation
   - Who to contact
6. Prevention tips for future

Make it easy to follow, not technical.
```

**3. Escalation Response Template**
```
Create a response for escalating a customer issue.

Issue: [TYPE]
Customer sentiment: [EMOTION - angry/disappointed/concerned]
Reason for escalation: [WHY_ESCALATING]
Target resolution path: [HOW_WE'LL_FIX]

Template should:
1. Acknowledge the escalation respectfully
2. Apologize for the need to escalate (take responsibility)
3. Introduce the senior team member
4. Brief them on what will happen next
5. Set clear timeline for next communication
6. Demonstrate seriousness (show this is priority)
7. Give them a contact person
8. Empower them to reach out directly if needed

Rebuild trust while escalating.
```

## PROMPT TIPS FOR SUCCESS

### For All Users:
1. **Be Specific**: The more detail you provide, the better the output
2. **Provide Context**: Tell Claude what matters for this particular situation
3. **Specify Format**: Tell Claude exactly how you want the answer (email, bullet points, table, etc.)
4. **Iterate**: First output is usually good, but refinement makes it great
5. **Save Winners**: Keep prompts that work well for future use

### Common Patterns:
- **[BRACKETED_ITEMS]**: Replace with your specific information
- **Tone Markers**: Specify "professional," "casual," "urgent," etc.
- **Structure Requests**: Ask for "bullet points," "paragraphs," "tables"
- **Length Guidance**: Specify "keep under 200 words" or "comprehensive"
- **Examples**: Providing examples of good output improves results

### Prompt Library Best Practices:
1. Test each prompt with real data before adding to your library
2. Document what works well about each prompt
3. Keep variations for different contexts
4. Update prompts based on what you learn
5. Share successful prompts with your team
